mend is one zero-dependency Node 22 CLI that applies AI-model edits in all four common formats — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON editor calls — to one written specification, matching drifted whitespace at three tiers and writing every file or none. It passes all 100 public practice checks.

## Run it

```sh
node main.ts fix.patch
```
